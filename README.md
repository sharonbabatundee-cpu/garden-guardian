# Garden Guardian

Welcome to **Garden Guardian**, a browser-based garden simulation game!

## Live Game
🔗 https://sharonbabatundee-cpu.github.io/garden-guardian

## About
Garden Guardian is an interactive gardening game where players plant, water, and harvest plants while managing their garden. The game includes upgrades, achievements, game progress tracking, and interactive gameplay features.

## Technologies Used
- HTML
- CSS
- JavaScript
- GitHub Pages

## Features
- 🌱 Plant and grow different plants
- 💧 Water and care for plants
- 🌻 Harvest fully grown plants
- 🪙 Earn and spend coins
- 🛠️ Purchase garden upgrades
- 🏆 Unlock achievements
- 📊 Track game progress and statistics

## Project Structure
- `index.html` - Game structure
- `css/style.css` - Game styling
- `js/script.js` - Game logic and functionality
- `images/` - Game images and assets
